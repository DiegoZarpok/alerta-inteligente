# Fonte de dados: INMET

> Origem: Descrição própria de fonte pública  
> Tipo: Real (público)  
> Nível: todos

O Instituto Nacional de Meteorologia (INMET) disponibiliza dados de estações meteorológicas automáticas, incluindo precipitação, temperatura e umidade, além de séries históricas para download.

Uso no projeto: referência para a chuva observada na região. Para treinar o modelo, o projeto usa os postos pluviométricos da ANA dentro da bacia, que têm séries mais longas e são os mesmos analisados pelo estudo da UESC.
