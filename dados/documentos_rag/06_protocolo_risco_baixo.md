# Protocolo de resposta: risco baixo

> Origem: FICTÍCIO - elaborado pelo grupo para o projeto  
> Tipo: Fictício

[DOCUMENTO FICTÍCIO PARA FINS ACADÊMICOS]

Situação: probabilidade de cheia abaixo de 30%.

Ações do sistema: registrar a leitura no banco; não enviar mensagem à população.

Orientação geral (caso o morador consulte /risco): manter a rotina normal; acompanhar a previsão do tempo; manter desobstruídos os bueiros e as calhas da residência; ter à mão o kit de emergência (ver documento 09).
